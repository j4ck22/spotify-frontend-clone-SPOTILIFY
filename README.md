# Spotify Clone

A responsive front-end clone of Spotify built for educational purposes.

> This project is not affiliated with or endorsed by Spotify.

## 📖 About

This project was created to improve my front-end development skills by recreating the Spotify interface using modern web technologies.

## 🚀 Technologies

- HTML5
- CSS3
- JavaScript

## ✨ Features

- Responsive layout
- Modern user interface
- Navigation menu
- Music cards
- Hover animations
- Mobile-first design
